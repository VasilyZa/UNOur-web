# UNOur Web

一张留给朋友的 UNO 牌桌。Svelte 5 + TypeScript + Vite，独立于 Go 后端的前端项目。

## 开始

Node.js 22.12+，建议使用 Node.js 24 LTS。

```sh
npm ci
npm run dev
```

打开 http://localhost:5173。默认进入带电脑玩家的**交互试玩**，不需要后端。可以选牌、出牌、摸牌、跳过、换色，在偏好设置中体验「两秒喊 UNO」。试玩使用简化场景；完整规则由 Go 后端结算。

## 连接 Go 后端

后端默认地址 `http://127.0.0.1:8088`，Vite 将 `/api` 代理到该地址。后端会验证浏览器的 Origin，开发时这样运行后端：

```sh
# 在 Go 后端目录执行
UNO_ALLOWED_ORIGINS=http://localhost:5173 make run
```

前端点击右上角房间图标，输入昵称创建房间。复制邀请链接，朋友打开后输入昵称加入；至少两人时房主可以开局。也可以直接输入房间号，字母区分大小写。

后端运行在其他地址时：

```sh
cp .env.example .env.local
# 编辑 API_PROXY_TARGET，然后重新启动 npm run dev。
```

手机访问开发机的局域网地址时，后端 `UNO_ALLOWED_ORIGINS` 也要加入该完整地址，例如 `http://192.168.1.10:5173`；多个来源用逗号分隔。Vite 开发服务器默认监听所有网卡，仅用于开发。

联机模式支持创建/加入、开局、出牌、摸牌、跳过、+4 质疑、UNO 声明与漏喊罚摸。当前后端只有 HTTP API，这版使用约 900ms 轮询；隐藏页面暂停轮询，返回后恢复。传输层可以独立替换为推送实现。

## 手机和交互

- 竖屏优先：对手在上、牌堆在中、手牌与操作在下；短屏收起次要说明。
- 手牌较多时原生横向滚动；点选后确认出牌，避免误触即出。
- UNO：剩一张牌时，立即点中央按钮或按空格键。输入框、打开的面板中不拦截空格。
- UNO 处罚使用后端窗口 ID 幂等上报；过早上报会延后重试。网络延迟可能影响两秒声明，以服务器收到请求的时间为准。
- 动效只用于反馈、牌的空间变化和面板进出，约 120–250ms。系统减少动态效果偏好或「轻柔动效」设置会移除位移动画。
- 使用 `dvh`、安全区边距、16px 输入字号，保留页面缩放；触屏不会触发悬停动效。

浏览器中的布局检查覆盖 320×568、360×780、390×844、430×932、平板与桌面。真实手机的刘海、浏览器工具栏、软件键盘和设备帧率仍需实机确认。

## 会话与请求

联机凭证只保存在当前浏览器的 localStorage，不写入 URL 或日志。每个站点在一个浏览器中保存一个最近座位；刷新恢复原会话，同房间邀请优先复用已有座位。切换试玩保留凭证，设置里可返回联机牌桌。清理本站浏览器数据会丢失座位凭证。

普通命令携带 `expected_version`，失败后读取最新状态，让玩家决定是否继续；不自动重发摸牌/出牌，防止网络结果不确定时重复执行。过期的轮询和恢复响应不能覆盖新牌桌或清除新会话。

## 结构

```text
src/
  App.svelte              牌桌交互、会话与面板协调
  lib/components/         SVG 卡牌、玩家、手牌、牌桌、原生 dialog 和面板
  lib/game/types.ts       后端 DTO 与可出牌提示（最终由服务器判定）
  lib/game/api.ts         HTTP、超时、错误边界
  lib/game/online.ts      联机同步、版本与请求取消
  lib/game/demo.ts        明确标注的交互试玩
  lib/game/bootstrap.ts   会话恢复的生命周期保护
  lib/game/session.ts     本地凭证存储
  styles/                 共享视觉与动效样式
```

无运行时 UI 组件库、游戏引擎、远程字体或位图依赖。图标、头像、牌面均为本地 SVG。新增后端规则时更新提示和规则说明；任何新增效果仍以服务器为准。

## 检查和构建

```sh
npm run check
npm test
npm run format:check
npm run build
npm run preview
```

构建产物是 `dist/` 静态文件。测试覆盖请求认证与版本、网络错误不重复发送、UNO 窗口与罚牌幂等、迟到状态保护、恢复请求隔离和叠加提示。

部署时将 `dist/` 放入静态站点，并将 `/api/` 原样反向代理到 Go 服务；配置后端允许该站点的完整 Origin。分域部署可在构建时设置 `VITE_API_ORIGIN=https://api.example.com`，同时配置后端允许前端来源。

前端不创建或迁移数据库；房间和游戏数据由 Go 后端 SQLite 保存。本仓库不关联后端 Git remote。
